1개요

만드는 이유

  • 공공기관·학교 문서는 대부분 한글(HWP) 형식이고, 회사·해외 문서는 워드(DOCX) 형식입니다. 두 형식을 함께 다루려면 유료 프로그램 두 개가 필요합니다.
  • 한글 프로그램이 없는 PC에서는 HWP 문서를 제대로 열거나 고치기 어렵고, 워드로 바꾸려면 다른 사람에게 부탁해야 합니다.

목표

  • 하나의 프로그램으로 한글·워드 문서를 모두 열고 고치고 저장합니다.
  • 한컴·MS 프로그램이 설치되어 있지 않은 PC에서도 서로 변환합니다.
  • 한글 프로그램과 비슷한 익숙한 화면으로, 마우스(클릭·터치)만으로 쉽게 씁니다.
  • 무료로 배포합니다. 설치형(Windows)과 웹판(브라우저) 두 가지로 제공합니다.

기술 바탕

한글 문서 처리는 오픈소스 엔진 rhwp(MIT 라이선스, 수정·재배포 허용)를 바탕으로 하고, 발견한 결함은 엔진 소스를 직접 고쳐 다시 빌드해 씁니다. 워드 편집기와 형식 변환기는 자체 개발했습니다.

4시장 상황과 차별점

rhwp 엔진이 공개된 뒤 이를 바탕으로 한 한글 편집 프로그램(설치형 포함)이 나오고 있으며, 한글 문서 수요가 큰 만큼 앞으로 더 늘어날 것으로 봅니다. 엔진이 같으면 기본 품질도 비슷해지므로, 엔진 바깥의 기능에서 차이를 만듭니다.

2단계: 공유 폴더 협업 방식

사용자가 이미 쓰는 클라우드 드라이브(네이버 MYBOX, 구글 드라이브, OneDrive 등)의 공유 폴더에 문서를 두고, 프로그램이 다음을 처리합니다. MS 오피스가 공유 폴더에서 쓰는 방식과 같습니다.

기능동작
편집 잠금누군가 문서를 열면 다른 사람에게 "○○님 편집 중"이 표시되고 읽기 전용으로 열림
바뀐 내용 알림보고 있는 문서가 다른 사람에 의해 저장되면 "새 내용이 있습니다" 안내 후 다시 불러오기
버전 기록저장할 때마다 이전 판을 보관해 잘못 고친 경우 되돌리기
덮어쓰기 방지두 사람이 거의 동시에 저장하면 한쪽을 사본으로 남기고 알림
서버 없이 운영: 문서 보관·보안·용량은 사용자의 드라이브가 맡으므로 별도 서버가 필요 없고, 운영 비용과 개인정보 관리 부담이 없습니다. 이 기능은 설치형(Windows)에서 제공합니다.
